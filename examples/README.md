# Lumina Engine Examples

This directory contains examples for the Lumina Engine.

**Note:** The engine is currently undergoing a major transition to an AI-native architecture. The examples in this directory are considered legacy and may not work with the latest version of the engine. They are being kept for archival purposes.

For the latest information on how to create games with Lumina, please refer to the [AI-Native Plan](docs/AI_NATIVE_PLAN.md) and the `examples/easy-game-creation` directory.
